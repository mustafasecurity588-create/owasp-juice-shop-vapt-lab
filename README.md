# OWASP Juice Shop – Web Application Security Assessment with Manual Validation

## Project Overview

This repository contains a self-initiated Web Application Security Assessment of OWASP Juice Shop, an intentionally vulnerable application developed for security training and testing.

The objective was to practice vulnerability assessment, analyze security configurations, manually validate selected findings, collect technical evidence, and prepare a professional security assessment report.

## Lab Environment

- Target: OWASP Juice Shop
- Environment: Local Docker Lab
- Target URL: `http://127.0.0.1:3000`
- Security Testing Tool: OWASP ZAP
- Additional Tools: cURL and Browser Developer Tools

## Assessment Activities

- Automated web application scanning
- HTTP security header analysis
- Content Security Policy (CSP) assessment
- Cross-Origin Resource Sharing (CORS) analysis
- JavaScript content and information disclosure review
- Manual validation of selected findings
- Evidence collection and remediation recommendations

## Repository Contents

- `Report/` – Final assessment report in PDF format.
- `Evidence/` – Sanitized screenshots supporting the findings.
- `Methodology/` – Testing approach and validation notes.

## Scope and Disclaimer

This assessment was conducted independently in a locally hosted OWASP Juice Shop training environment.

It is a learning and portfolio project, not a paid client engagement or a security audit of a production application.

Findings and their severity should be interpreted within the documented lab scope and testing limitations.
